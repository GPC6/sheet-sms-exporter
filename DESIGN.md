# Design

Mode: Operate. A compact Korean desktop utility for repeat spreadsheet exports.
Use a quiet light workspace, a dark ink masthead, blue action buttons, and aligned form rows.
The main composition is a single task surface with source settings on the left and an export summary on the right.
Typography uses the operating system's Korean sans-serif for desktop legibility. Color marks actions and real status.
No decorative imagery, fake preview records, remote fonts, or personal data in the summary.
Keep account identity, requested access, generation state, and partial-success recovery visible.

Assumptions are recorded in PRODUCT.md; this first version uses the existing link-based workflow.
